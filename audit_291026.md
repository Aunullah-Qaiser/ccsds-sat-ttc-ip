## 1. Executive Summary

Since the 2nd Critical Review, the IP has undergone a major transition from an **algorithmic and protocol proof-of-concept** to a **pre-hardware, tape-out-ready transceiver** designed for direct interfacing with an Analog Devices AD9361 RF Agile Transceiver and flight OBCs.

### Summary of Completed Milestones:
1. **Resolution of Finding 1 (Downlink TX Symbol CDC)**: A dedicated dual-clock Gray-code SECDED FIFO (`u_tx_phy_cdc_fifo`) now bridges `clk_tx_sym` (50 MHz) to `clk_adc_iq` (120 MHz), isolating the PHY modem from symbol-clock jitter.
2. **Resolution of Finding 2 (Target Device Sizing)**: Top-level generics (`ENABLE_SDLS`, `ENABLE_UL_LDPC`, `IQ_BUS_WIDTH`) were added. The full un-pruned core targets **Xilinx Zynq-7020 (`54.25%` LUT utilization)**, **Zynq-7045 (`13.27%`)**, or **Kintex UltraScale (`11.91%`)**, while the compact CubeSat profile (`ENABLE_SDLS=0, ENABLE_UL_LDPC=0`) fits into the **Zynq-7010 at `47.34%` (8,332 LUTs)**.
3. **AD9361 16-Bit I/Q Transceiver Adaptation**: Configurable 16-bit I/Q buses with internal 12-bit slicing (`rx_i_adc_in[11:0]`) and 4-bit DAC zero-padding (`{phy_tx_i_12b, 4'b0000}`) were integrated for direct connection to the `axi_ad9361` IP.
4. **Per-Domain Asynchronous-Assert / Synchronous-Deassert Reset Bridges**: Four independent 2-FF reset synchronizer bridges (`rst_sys_n`, `rst_tc_n`, `rst_tx_n`, `rst_adc_n`) eliminate cross-domain reset release skew.
5. **Uplink Rx Asynchronous CDC FIFO & Bit-to-LLR Serializer**: Incoming demodulated bytes from `u_phy_modem` (`clk_adc_iq`) are safely bridged into `clk_tc_safe` via `u_rx_phy_cdc_fifo` and serialized into soft LLRs (+7/-7), with LDPC abort pulses properly gated during BCH CLTUs.
6. **Runtime SDLS Master Key & Security Association (SA) Provisioning**: Memory-mapped AXI4-Lite registers (`0x28..0x50`) allow runtime key loading and SA table management from flight software.
7. **True Chip-to-Chip Stage 11 RF Loopback Closure**: All testbench symbol bypasses (`sc_ul_sym_tvalid = 0`) were eliminated. All 480 valid CCSDS RF matrix configurations (10 waveforms $\times$ 4 bands $\times$ 3 UL sizes $\times$ 4 DL modes) passed with 100% coverage across 12 parallel threads in 34.01 seconds.
8. **Multi-Configuration Space Flight Channel Closure (Stage 12)**: Swept dynamic S-curve Doppler (+512 AOS $\to$ 0 TCA $\to$ -512 LOS), oscillator phase noise, two-way slant-range delay, and Rician deep scintillation fades with autonomous COP-1 Go-Back-N recovery.

## 3. Critical Findings & Residual Gaps

### Finding 1 (Flow-Control Architecture): Buffer Overflow Hazard on `u_tx_phy_cdc_fifo`

> [!WARNING]
> While `u_tx_phy_cdc_fifo` successfully isolates the `clk_tx_sym` (50 MHz) and `clk_adc_iq` (120 MHz) clock domains, the write-side backpressure signal is unconnected, creating a buffer overflow vulnerability during long telemetry frames.

* **Target File**: [`rtl/ccsds_sat_ttc_top.sv` lines 1512–1529](file:///c:/Users/abc12/Documents/ccsds_sat_ttc_ip/rtl/ccsds_sat_ttc_top.sv#L1512-L1529).
* **Observed Circuitry**:
  ```systemverilog
  ccsds_cdc_fifo_ecc #(
    .DATA_WIDTH    (8),
    .DEPTH_WORDS   (128),
    .ROLLBACK_MODE (1'b0),
    .WATERMARK_MODE(1'b0)
  ) u_tx_phy_cdc_fifo (
    .clk_wr          (clk_tx_sym),
    .rst_wr_n        (rst_tx_n),
    .clk_rd          (clk_adc_iq),
    .rst_rd_n        (rst_adc_n),
    .cut_through_en  (1'b1),
    .s_axis_tdata    (m_axis_dl_cad_tdata),
    .s_axis_tvalid   (m_axis_dl_cad_tvalid && m_axis_dl_cad_tready),
    .s_axis_tready   (tx_phy_fifo_wr_ready_unused),  // <-- UNCONNECTED
    .rollback_overflow_err (tx_phy_fifo_ovf_unused) // <-- UNCONNECTED
  );
  ```
* **Failure Mechanism**:
  1. `u_tx_phy_cdc_fifo` has a capacity of **128 bytes** (`DEPTH_WORDS = 128`).
  2. Its input stream comes from `u_tx_hwm_cdc_fifo` (capacity **512 bytes**), which drains at 1 byte/clock (50 MB/s on `clk_tx_sym`) whenever the top-level port `m_axis_dl_cad_tready` is asserted.
  3. `tx_phy_fifo_wr_ready_unused` is left open; `u_tx_phy_cdc_fifo` **cannot push back** on `u_tx_hwm_cdc_fifo`.
  4. In flight operation, standard CCSDS TM Transfer Frames are **892, 1024, or 1115 bytes** long.
  5. The baseband modulator (`u_phy_modem`) consumes symbols at the configured RF symbol rate (e.g., 1 Msps = 125 kB/s in BPSK; 25 Msps = 3.125 MB/s).
  6. **Result**: If an external system or testbench holds `m_axis_dl_cad_tready = 1`, `u_tx_hwm_cdc_fifo` will burst bytes into `u_tx_phy_cdc_fifo` at 50 MB/s. After 128 bytes, `u_tx_phy_cdc_fifo` **will overflow and drop the remaining 700–900 bytes of the frame**.
  7. **Secondary Risk**: If an integrator uses the IP in RF-only mode and leaves `m_axis_dl_cad_tready` unconnected or tied to 0, `m_axis_dl_cad_tvalid && m_axis_dl_cad_tready` will be `0`, and **the RF transmitter will never transmit any data**.
* **Why Stage 11 Passed**:
  In `tb_stage11_top_to_top_rf_link.sv` (Subtest 11.3), the telemetry packet was 16 bytes, resulting in a total CADU length of **64 bytes** (including ASM, header, and RS parity). Because $64 < 128$, the entire frame fit in `u_tx_phy_cdc_fifo` without triggering an overflow.
* **Remediation**:
  Combine the backpressure from the physical FIFO and the external CADU port so `u_tx_hwm_cdc_fifo` paces its output according to the slower consumer:
  ```systemverilog
  // In rtl/ccsds_sat_ttc_top.sv:
  logic tx_phy_fifo_wr_ready;

  // u_tx_hwm_cdc_fifo read-ready must be paced by the RF FIFO:
  assign tx_hwm_rd_ready = tx_phy_fifo_wr_ready && m_axis_dl_cad_tready;

  u_tx_hwm_cdc_fifo (
    ...
    .m_axis_tready (tx_hwm_rd_ready),
    ...
  );

  u_tx_phy_cdc_fifo (
    ...
    .s_axis_tvalid (m_axis_dl_cad_tvalid && tx_hwm_rd_ready),
    .s_axis_tready (tx_phy_fifo_wr_ready),
    ...
  );
  ```

* **Target File**: [`rtl/ccsds_sat_ttc_top.sv` line 689](file:///c:/Users/abc12/Documents/ccsds_sat_ttc_ip/rtl/ccsds_sat_ttc_top.sv#L689).
